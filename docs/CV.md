# Mis Gastos en el CV

## Descripción breve

**Mis Gastos — Aplicación de finanzas personales.** Proyecto personal con interfaz responsive en JavaScript, backend en TypeScript/Deno y PostgreSQL/Supabase e integración con Enable Banking para importar movimientos y saldos. Incluye clasificación automática, deduplicación, control de acceso y pruebas automatizadas. Desarrollo iterativo con asistencia de IA.

Añade el enlace del repositorio una vez publicado en tu cuenta de GitHub.

## Competencias demostrables

- Diseño de flujos de datos entre interfaz, base de datos y API externa.
- Modelado de movimientos, saldos, categorías y traspasos.
- Tratamiento de errores, paginación, idempotencia y tareas programadas.
- Separación de configuración pública y secretos del servidor.
- Validación de lógica financiera y permisos mediante pruebas.
